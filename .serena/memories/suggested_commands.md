# Suggested Commands

- Preview subagent install/removal: `node plugins/codex-orchestrator/scripts/install-subagents.mjs --dry-run`.
- Install bundled subagent definitions: `node plugins/codex-orchestrator/scripts/install-subagents.mjs`.
- Install dependencies: `bun install`.
- Tests: `bun run test`.
- Typecheck: `bun run typecheck`.
- Lint: `bun run lint`.
- Format TS/JS: `bun run format`.
- OpenSpec status for a change: `openspec status --change <name>`.
