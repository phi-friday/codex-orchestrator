# Task Completion

- Before claiming implementation completion, run: `bun run test`, `bun run typecheck`, and `bun run lint`.
- For OpenSpec changes, also run `openspec status --change <name>` and ensure task checkboxes reflect completed work.
- If a change is truly Markdown-only and runtime checks are skipped, explicitly record why instead of implying they passed.
- Do not use destructive git cleanup. Respect dirty worktree changes that may belong to the user.
